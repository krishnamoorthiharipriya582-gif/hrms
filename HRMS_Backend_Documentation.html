1. Backend System Architecture & Technology Stack

The backend of the HRMS enterprise platform is engineered with Spring Boot 3.3.4 running on Java 21 LTS. It implements a layered, domain-driven architecture characterized by loose coupling, high cohesion, stateless RESTful web services, and robust transactional management backed by PostgreSQL 18.

Architectural Layer Technology / Framework Design Responsibilities & Implementation Details
Runtime & Language Java 21 LTS Leverages modern Java features including immutable Records for DTOs, Pattern Matching for enhanced type safety, and efficient heap memory management.
Web Microframework Spring Boot 3.3.4 Provides embedded Tomcat container, auto-configured Spring MVC controllers, Jackson JSON serialization, and Spring Actuator metrics.
Security Gateway Spring Security 6 Stateless JWT token verification filter chain, BCrypt password hashing (Cost Factor 12), and role-based method security via @PreAuthorize.
ORM & Persistence Spring Data JPA / Hibernate 6 Object-relational mapping, transactional session management (@Transactional), custom JPQL queries, and HikariCP connection pooling.
Relational Database PostgreSQL 18 ACID transactional persistence, 17 normalized 3NF tables, foreign key constraints with cascade behaviors, and B-Tree indexing on primary and unique keys.
API Protocol RESTful Web Services Standardized HTTP status codes (200 OK, 201 Created, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found), RFC 7807 error structures.

1.1 Layered Domain Architecture

Every functional module adheres strictly to an inversion-of-control (IoC) layered flow:

HTTP Request ➔ Filter Chain (JWT Auth) ➔ REST Controller ➔ Service Layer (Business Rules) ➔ Spring Data Repository ➔ PostgreSQL Database
  • Controller Layer: Validates incoming JSON payloads (@Valid, @NotNull) and maps HTTP verbs (GET, POST, PUT, DELETE) to internal operations.
  • Service Layer: Contains business rules, transactional boundaries, mathematical formula calculations (PF/ESI/PT/LOP), and regulatory exporter services.
  • Repository Layer: Extends JpaRepository<Entity, UUID/Long>, providing optimized SQL queries, dynamic pagination, and sorting capabilities.
  • Entity Layer: JPA entities annotated with @Entity, @Table, @ManyToOne, @OneToMany with strictly managed foreign key cascading.

// JwtTokenProvider HMAC-SHA512 Generation Pipeline
public String generateToken(Authentication authentication) {
    UserDetails userPrincipal = (UserDetails) authentication.getPrincipal();
    Date now = new Date();
    Date expiryDate = new Date(now.getTime() + jwtExpirationMs);

    return Jwts.builder()
        .setSubject(userPrincipal.getUsername())
        .claim("role", userPrincipal.getAuthorities().iterator().next().getAuthority())
        .setIssuedAt(new Date())
        .setExpiration(expiryDate)
        .signWith(SignatureAlgorithm.HS512, jwtSecret)
        .compact();
}

5. Core Algorithmic & Mathematical Business Engines

5.1 Shift Attendance & 09:15 AM Grace Period Engine

The attendance engine enforces strict workplace discipline while accommodating unavoidable commuting delays via an automated grace calculation:

Punch Time WindowAssigned StatusSalary Impact & Penalty Logic
09:00 AM – 09:15 AMPRESENT (Punctual)Full day credit; 15-minute grace window cushions minor travel delays.
09:16 AM – 10:00 AMLATE MARKRecorded as Late; accumulation of 3 late marks triggers automatic 0.5-day LOP.
10:01 AM – 01:00 PMHALF DAYHalf-day salary deduction applied automatically to the monthly payroll engine.
After 01:00 PM / MissingABSENTMarked Absent; triggers full-day Loss of Pay (LOP) deduction unless regularized.
 
// Attendance Grace Engine Implementation
public AttendanceStatus calculatePunctuality(LocalTime punchInTime) {
    LocalTime shiftStart = LocalTime.of(9, 0);
    LocalTime graceEnd   = LocalTime.of(9, 15);
    LocalTime lateEnd    = LocalTime.of(10, 0);
    LocalTime halfDayEnd = LocalTime.of(13, 0);

    if (punchInTime.isBefore(graceEnd) || punchInTime.equals(graceEnd)) {
        return AttendanceStatus.PRESENT;
    } else if (punchInTime.isBefore(lateEnd) || punchInTime.equals(lateEnd)) {
        return AttendanceStatus.LATE;
    } else if (punchInTime.isBefore(halfDayEnd)) {
        return AttendanceStatus.HALF_DAY;
    } else {
        return AttendanceStatus.ABSENT;
    }
}

5.2 Indian Statutory Payroll Calculation Engine

The payroll engine executes formulaic statutory deductions compliant with the Employees' Provident Funds Act 1952, the Employees' State Insurance Act 1948, and Indian Income Tax statutes:

Gross Earnings = Basic + HRA (50% Basic) + Special Allowance + Conveyance + Performance Bonus
Employee PF (12%) = Min(Basic, ₹15,000) × 12% (Max: ₹1,800 / month)
Employee ESI (0.75%) = Gross Salary × 0.75% (Applicable only if Gross Salary ≤ ₹21,000)
Employer PF (12%) = 3.67% (EPF) + 8.33% (EPS, cap ₹1,250) + 0.5% (EDLI) + 0.5% (Admin)
Employer ESI (3.25%) = Gross Salary × 3.25% (Applicable only if Gross Salary ≤ ₹21,000)
Loss of Pay (LOP) = (Gross Salary ÷ Total Days in Month) × Unapproved Absent Days
Net Payable Salary = Gross Earnings - (Employee PF + Employee ESI + State PT + TDS + LOP)
