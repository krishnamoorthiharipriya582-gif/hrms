CHAPTER 4
SYSTEM DESIGN

4.1 MODULE DESCRIPTION

The HRMS Enterprise platform is partitioned into four primary functional modules, each supported by dedicated database entities:

4.1.1 Employee Onboarding & Master Directory Module

Manages the transition of job candidates to active employees, storing personal identity particulars, contact details, bank credentials, and departmental affiliations.

Table 4.1.1 Employee Master Entity Data Dictionary
Field Name Data Type Constraints Description
idUUIDPRIMARY KEYUnique system identifier for employee
employee_codeVARCHAR(20)UNIQUE, NOT NULLFormal employee code (e.g., EMP001)
full_nameVARCHAR(100)NOT NULLLegal name of the employee
emailVARCHAR(100)UNIQUE, NOT NULLOfficial corporate email address
department_idUUIDFOREIGN KEYReferences primary department entity
designation_idUUIDFOREIGN KEYReferences assigned job role designation
employee_statusVARCHAR(20)NOT NULLStatus: ACTIVE, PROBATION, NOTICE, EXITED
pan_numberVARCHAR(10)NOT NULLStatutory Permanent Account Number

4.1.2 Attendance, Shifts & Geofencing Module

Records real-time punch timestamps, geofence coordinates, and enforces shift punctuality rules.

Table 4.1.2 Attendance & Shift Tracking Data Dictionary
Field Name Data Type Constraints Description
idUUIDPRIMARY KEYUnique attendance transaction ID
employee_idUUIDFOREIGN KEY, NOT NULLReferences parent employee entity
attendance_dateDATENOT NULLDate of attendance record
punch_in_timeTIMESTAMPNULLABLETime of check-in punch
punch_out_timeTIMESTAMPNULLABLETime of check-out punch
statusVARCHAR(20)NOT NULLON_TIME, LATE, HALF_DAY, ABSENT
punch_typeVARCHAR(20)NOT NULLPUNCH_IN, PUNCH_OUT, REGULARISATION

4.1.3 Statutory Payroll Engine & Leave System

Calculates monthly salaries and manages employee leave quotas.

Table 4.1.3 Indian Statutory Payroll & Structure Data Dictionary
Field Name Data Type Constraints Description
idUUIDPRIMARY KEYUnique payroll record ID
payroll_run_idUUIDFOREIGN KEY, NOT NULLReferences monthly payroll run batch
employee_idUUIDFOREIGN KEY, NOT NULLReferences employee recipient
gross_salaryNUMERIC(12,2)NOT NULLGross monthly earnings (Basic+HRA+Special)
pf_employeeNUMERIC(10,2)NOT NULLStatutory EPF deduction (12% of wage ceiling)
esi_employeeNUMERIC(10,2)NOT NULLStatutory ESIC deduction (0.75% of gross)
net_salaryNUMERIC(12,2)NOT NULLFinal take-home salary after all deductions

4.1.4 Statutory Compliance & Admin Configuration Module (FR12)

Maintains dynamic compliance parameters in PostgreSQL, enabling live rate updates without system recompilation.
