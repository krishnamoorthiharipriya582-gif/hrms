SYSTEM REQUIREMENTS

3.1 HARDWARE REQUIREMENTS

The hardware specifications required to deploy and execute the HRMS Enterprise platform are outlined below:

  • Processor: Intel Core i5 / AMD Ryzen 5 (2.4 GHz quad-core or higher)
  • Random Access Memory (RAM): 8 GB minimum (16 GB recommended for concurrent backend and Vite compilation)
  • Hard Disk / Storage: 512 GB Solid State Drive (SSD) with minimum 10 GB free space
  • Network: Standard TCP/IP broadband connectivity (minimum 10 Mbps)

3.2 SOFTWARE REQUIREMENTS

  • Operating System: Windows 10 / 11 (64-bit), Linux (Ubuntu 22.04+ LTS), or macOS
  • Integrated Development Environment (IDE): Visual Studio Code / IntelliJ IDEA Ultimate
  • Runtime Environments: Java Development Kit (JDK 17 or JDK 25 LTS), Node.js (v18.x or v20.x LTS)
  • Backend Framework: Spring Boot 3.3.4 (Spring Web, Spring Security, Spring Data JPA, Hibernate ORM)
  • Frontend Framework: React 18, Vite 8, Lucide React Icon Library, Tailwind/Modern CSS
  • Database Engine: PostgreSQL 18 with HikariCP Connection Pool
  • Build Tools: Apache Maven 3.9.x, npm 10.x

3.3.1 FRONTEND ARCHITECTURE (REACT 18 & VIRTUAL DOM)

ReactJS is an open-source, component-based JavaScript library maintained by Meta for building dynamic user interfaces. In this project, React 18 is paired with Vite 8 to achieve instantaneous build compilation and modular application state handling.

The Virtual DOM: Instead of performing slow, expensive direct manipulations on the real browser Document Object Model (DOM), React maintains a lightweight virtual representation in memory. When state updates occur (e.g., when an employee logs in or regularises attendance), React computes an optimized diff between the previous and current virtual DOM trees, updating only the affected nodes in the real browser DOM.

Key Frontend Features Employed:

  • Declarative Component Architecture: Modular encapsulation of KPI cards, data tables, modal popups, and navigation sidebars.
  • Hooks & State Management: Systematic use of useState, useEffect, and useCallback to synchronize local view state with backend REST APIs.
  • Stateless Axios/Fetch Interceptors: Automatically attaches the active JWT Bearer token to all outgoing HTTP request headers.

3.3.2 BACKEND ARCHITECTURE (SPRING BOOT 3 & JPA)

Spring Boot 3 is an enterprise-grade Java framework that simplifies the configuration, deployment, and execution of scalable microservices and RESTful web applications.

  • Spring Web (MVC): Handles HTTP request dispatching, controller mappings, JSON payload serialization, and exception handling.
  • Spring Data JPA & Hibernate: Eliminates manual SQL boilerplate code by mapping relational database tables directly to Java entity classes using ORM annotations (@Entity, @Table, @ManyToOne).
  • Spring Security & JWT: Intercepts all incoming HTTP requests via a custom JwtAuthenticationFilter, validating token digital signatures before permitting access.
  • PostgreSQL 18: Provides transactional ACID guarantees, relational foreign key constraints, and robust data persistence.
