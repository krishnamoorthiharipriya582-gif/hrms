ABSTRACT

The Employee Onboarding and HR Management System (HRMS) is an enterprise-grade full-stack human capital management solution engineered to unify, automate, and streamline organizational HR processes across the entire employee lifecycle. Traditional HR operations frequently depend on fragmented spreadsheets, disconnected paper forms, and disparate standalone applications for attendance and payroll. These manual workflows inevitably introduce severe data redundancies, delayed employee onboarding, attendance tracking inaccuracies, statutory labor compliance risks, and computational payroll errors.

The proposed system resolves these critical bottlenecks through a robust, centralized web platform built on a Spring Boot 3 REST API backend, a high-performance React 18 / Vite 8 frontend, and a relational PostgreSQL 18 database engine. The system delivers complete functional coverage spanning candidate digital onboarding with KYC document verification, master employee profiles, dynamic multi-level organizational hierarchy visualization, and geofenced attendance tracking with an automated 09:15 AM grace cutoff. Furthermore, it incorporates policy-driven leave quota tracking (Casual, Sick, Earned, Comp-Off) and a dedicated Manager Approvals console.

A core strength of the platform is its comprehensive Indian Statutory Payroll Engine, which automates monthly gross-to-net salary computation by strictly enforcing Employees' Provident Fund (EPF 12%), Employees' State Insurance (ESIC 0.75% / 3.25%), Professional Tax (PT), Loss of Pay (LOP) calculations, and new tax regime standard deductions. The platform compiles statutory returns including EPFO Electronic Challan cum Return (PF-ECR .txt), ESIC Monthly Challan (.csv), Form 12BB tax declarations, and Form 24Q quarterly TDS filings.

Role-Based Access Control (RBAC) is enforced across four distinct personas (Super Admin, HR Manager, Department Manager, Employee) using stateless JSON Web Tokens (JWT) and BCrypt password encryption. A dynamic administrative module empowers authorized HR leaders to modify statutory percentages, ceilings, and compliance divisors in real time without requiring code modifications or server redeployments. An immutable audit logging engine records all data mutations to satisfy the strict data governance mandates of the Indian Digital Personal Data Protection (DPDP) Act 2023.
